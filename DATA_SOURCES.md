# Dataset source and attribution

## Bank Account Fraud (BAF), Base variant

- Provider: Sérgio Jesus and collaborators; official documentation maintained by Feedzai.
- Download page: https://www.kaggle.com/datasets/sgpjesus/bank-account-fraud-dataset-neurips-2022
- Dataset version used for the reproducible run: Kaggle version 2 (Base.csv only).
- License displayed by the Kaggle data card: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0).
- Description: synthetic, privacy-preserving application-fraud data generated from an anonymized real-world bank account opening fraud dataset; 1,000,000 examples, 30 application features, month, and fraud label.
- Research reference: Jesus et al. (2022), “Turning the Tables: Biased, Imbalanced, Dynamic Tabular Datasets for ML Evaluation,” NeurIPS 2022, https://doi.org/10.52202/068431-2432.
- Official source code and dataset documentation: https://github.com/feedzai/bank-account-fraud.

The project does not include or redistribute the raw dataset. Users must review the dataset's current terms before download or reuse. The Kaggle data license is separate from the Apache-2.0 license on Feedzai's code repository. This project's MIT license applies only to original code and documentation, not to BAF data or derived materials.

## Scope

This portfolio benchmark is non-commercial research and education. It excludes real cardholder or customer records, does not claim measured performance on live fraud, and does not publish trained weights or individual-level scores. Aggregate metrics are descriptive for the stated synthetic temporal split.
